# Dotfiles 🥑

My dotfiles, I don't think they'll work for ya but who knows. This is for Macs (`./setup`). I have a runbook in Obsidian with instructions.

## Linux

This now also supports Linux "remote devboxes", for the age of agents. Devboxes can run `./setup --profile devbox`, either via its Ansible playbook or via `dotfiles-sync` from the Mac, which pulls the latest pushed commits on the box and re-runs setup there.
